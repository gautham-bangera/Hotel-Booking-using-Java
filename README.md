## 📌 Overview

The Hotel Management System is a desktop-based application built using Java Swing. It allows users to book rooms, check availability, and manage hotel services.

---

## 🎯 Features

* 🔐 Login System
* 🏨 Room Booking (Single & Double)
* ❌ Availability Checking
* 🍽 Food Ordering
* 📊 Dashboard

---

## ▶️ How to Run

```bash
javac *.java
java LoginPage
```
